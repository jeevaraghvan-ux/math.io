## ✨ Features

- 🌈 **Vibrant Neon Dark Mode & Super Cool Loading Screen** — 3D gyroscopic rings, quantum math core orb, cyber grid, and telemetry diagnostic logs.
- 🔒 **Admin Security Vault** — High-security animated safe door with PIN authentication, web administration deck, and telemetry controls.

## 🚀 Publishing & Hosting

### Option A: GitHub Pages (Recommended)
1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit for math.io"
   ```
2. Create a new repository named `math.io` on [GitHub](https://github.com/new).
3. Connect and push:
   ```bash
   git remote add origin https://github.com/<your-username>/math.io.git
   git branch -M main
   git push -u origin main
   ```
4. In GitHub Repo: **Settings > Pages > Source**: Select branch `main` and `/ (root)`, then click **Save**.
5. Your app will be live at `https://<your-username>.github.io/math.io`.

### Option B: Vercel / Netlify
- **Netlify**: Drop this entire folder onto [app.netlify.com/drop](https://app.netlify.com/drop) for instant zero-config deployment.
- **Vercel**: Import your GitHub repo on [vercel.com](https://vercel.com) for automatic deployment previews on every commit.

## 💻 Running Locally

### Option 1: Visual Studio (.NET)
Open [`math.io.sln`](math.io.sln) or [`ConsoleApp1.sln`](ConsoleApp1.sln) and hit **F5** (or `dotnet run --project ConsoleApp1`) to launch the web client automatically in your default browser.

### Option 2: Pure Web Server
```bash
npx serve .
# Or Python
python -m http.server 8000
```
